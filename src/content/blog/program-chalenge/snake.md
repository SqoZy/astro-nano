Recently, I took on a coding challenge to create a classic Snake game, inspired by [The Coding Train's Snake tutorial](https://www.youtube.com/watch?v=AaGK-fj-BAM). The goal was to recreate the classic gameplay where you control a snake, eat food to grow, and avoid running into yourself or the walls.

I managed to build the basic version in a short amount of time, focusing on the core mechanics: movement, food spawning, and collision detection. It was a fun exercise in JavaScript and game logic. You can check out the result on my [Snake project page](/projects/project-7/snake).

This challenge was a great way to practice handling user input, game loops, and simple collision logic!
